# wells-risk-frontend

Фронтенд справочника критериев шкалы Уэллса для оценки риска тромбоза глубоких вен (ТГВ) и тромбоэмболии лёгочной артерии (ТЭЛА).
Лабораторная работа №5: `React` + `TypeScript` + `Vite` + `React Router` + `React-Bootstrap`.

Интерфейс гостя: две страницы — `лента` и `плитка` критериев. Данные берутся только из коллекции mock-объектов, без бэкенда, БД и MinIO.
Бэкенд: [wells-risk-backend](https://github.com/Dovletov-Seyran/wells-risk-backend).

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # сборка в dist
```

## Страницы

Интерфейс сделан под вертикальный экран телефона: на компьютере приложение отображается колонкой шириной 390px по центру.

### Панель навигации

Закреплена внизу всех страниц, 4 пункта:

| Пункт | Действие | Доступность |
|---|---|---|
| Лента | открывает ленту с первого критерия текущего списка плитки | доступен |
| Добавление | страница добавления критерия | недоступен (только для врача после входа) |
| Плитка | открывает плитку критериев | доступен |
| Вход | страница аутентификации | недоступен |

Активный пункт подсвечивается по текущему адресу.

### Плитка критериев — `/criteria`

Карточки опубликованных критериев в два столбца.

* **Фильтр «Вес критерия от … баллов»** — ползунок от −2 до +3 с шагом 0,5. Выбранное значение отображается рядом с подписью
* **Кнопка «Найти»** — оставляет критерии с весом не ниже выбранного. Ленту после фильтрации листают по найденным критериям
* **Карточка критерия** — изображение, вес в баллах, название, количество лайков. Нажатие открывает ленту с этого критерия

### Лента критериев — `/criteria/feed/:id`

Один критерий поверх его вертикального видео, видео проигрывается автоматически. `:id` — ид критерия.

* **Справа**: вес критерия в баллах, группа критерия, количество лайков
* **Кнопка «Следующий»** (стрелка вниз) — следующий критерий по порядку в текущем списке плитки
* **Внизу**: название критерия
* **Кнопка «Больше»/«Меньше»** — раскрывает и сворачивает краткое описание

### Изображение и видео по умолчанию

Если у критерия пустое поле `image_url` или `video_url`, показываются файлы из самого проекта:
`public/DefaultImage.jpg` и `public/DefaultVideo.mp4`. В mock так устроен критерий 15.
