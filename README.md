# Оценка риска тромбоэмболических осложнений по шкале Уэллса

Учебный проект по курсу «System Design + Web (ПСПР)»
Кафедра ИУ5, МГТУ им. Н.Э. Баумана, 2026

**Тема №13** (раздел «Медицина»)
**Группа:** ИУ5-55

## Предметная область

Справочник клинических критериев шкалы Уэллса для оценки риска тромбоза глубоких вен (ТГВ)
и тромбоэмболии лёгочной артерии (ТЭЛА).
